# Desktop WebView Stop dependency qualification

NativeCmpKit currently resolves `org.openjfx` 21.0.13 for Desktop. `Worker.cancel()` can reach `CANCELLED` while the HTTP peer still waits. `HTTP2Loader.fwkCancel()` sets a flag used to suppress callbacks. A request waiting for response headers has no body subscriber to observe the flag. The tested source change also cancels the `HttpClient` response future. [Issue #64](https://github.com/NativeCmpKit/NativeCmpKit/issues/64) · [Earlier verification decision](../decisions/0013-private-javafx-cancellation-candidate.md)

## First full-source verification run

The `openjfx-source-linux-x64` profile of the manual native verification workflow uses the complete `jfx21u` 21.0.13.1+1 source tree and the previously tested cancellation patch. The lock binds the annotated tag object, commit, tree, original loader, patch, Gradle Wrapper configuration and every admitted external Ivy file. GitHub's OpenJDK tag and commit records report unsigned objects. The check ties the build to their immutable identities. The ICU data and source archive both match the Unicode release's SHA-512 manifest and are separately pinned by SHA-256. The ANTLR tool from ANTLR matches the Maven Central artifact byte for byte. [Source lock](../../tests/dependency/javafx-http2-cancellation/source-sdk-lock.json) · [OpenJDK tag](https://github.com/openjdk/jfx21u/tree/21.0.13.1%2B1) · [ICU 77.1 release](https://github.com/unicode-org/icu/releases/tag/release-77-1)

The profile configures Gradle's local Ivy repository and enables compilation of native WebKit and Media. The artifact records the build command and exit code, source tree inventory, installed toolchain, SDK binary digests, ELF machine, and cancellation bytecode. The four existing native cases run on the newly built SDK without module injection. They cover a pending response before headers, incomplete plain and gzip bodies, and an independent concurrent request. Each requires peer EOF before teardown and a successful recovery on the same engine. The job uploads evidence only. [Workflow](../../.github/workflows/build-native-libs.yml) · [Fixture](../../tests/dependency/javafx-http2-cancellation/JavaFxPublicCancellationProbe.java)

Production qualification additionally requires a repeatable image and toolchain, matching native corresponding sources and notices for every shipped classifier, dependency provenance and security review, and ABI and packaged consumer results on Linux x64, Linux ARM64, macOS x64, macOS ARM64 and Windows x64. Verify public Stop, repeated loads, navigation replacement and disposal while work is pending. Observe peer termination, resource accounting after repeated use, concurrent isolation, and performance against the ordinary dependency. The physical-device and publication gates are required independently.
